# Azure Data Engineer Interview Kit

[![Content validation](https://img.shields.io/badge/content-validated-brightgreen)](scripts/validate_repository.py)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

A comprehensive, original preparation repository for Azure Data Engineering interviews and Microsoft DP-700. It contains solved coding problems, scenario questions, field guides, system designs, project architectures and career resources.

> This repository contains original practice material—not Microsoft exam dumps and not unauthorized copies of published books.

## Start here

1. Follow the [Azure Data Engineer roadmap](career/azure-data-engineer-roadmap.md).
2. Use the [DP-700 preparation guide](certification/dp-700/preparation-guide.md).
3. Build one of the [20 end-to-end projects](projects/20-end-to-end-projects.md).
4. Run the validation script to verify every advertised count.
